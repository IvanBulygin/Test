Gauntlet

CategoryProgramming
TypeSolo Project

Overview

A top-down dungeon crawler inspired by the classic Gauntlet arcade game. Features procedurally connected rooms, enemy spawners, and a tile-based map system with blue grid visualization for debugging and level editing.

Key Features

Implemented tile-based level generation, pathfinding algorithms for enemy navigation, and a room connection system. The project served as a deep dive into grid-based game architectures and real-time enemy management systems.
