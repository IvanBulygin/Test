Pong in Reflection

CategoryProgramming
TypeSolo Project

Overview

A minimalist reimagining of the classic Pong game with a twist — the playing field reflects and warps, creating unique gameplay challenges. An exercise in clean code architecture and precise collision handling.

Key Features

Features reflection-based ball physics, adaptive AI opponent with adjustable difficulty, and a minimalist visual style. The project focuses on tight game feel with precise input handling and satisfying ball-paddle interactions.
