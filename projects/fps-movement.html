FPS Movement

CategoryPrototypes
TypeSolo Project

Overview

A first-person shooter movement prototype focusing on responsive and satisfying character controls. Explores advanced movement mechanics like wall-running, sliding, bunny hopping, and momentum-based physics.

Key Features

Built a physics-driven character controller with smooth acceleration curves, air control, and surface-dependent movement modifications. The system prioritizes game feel and responsiveness, with tunable parameters for different movement archetypes.
