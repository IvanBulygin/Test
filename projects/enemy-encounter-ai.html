Enemy Encounter AI

CategoryPrototypes
TypeSolo Project

Overview

A prototype exploring enemy AI behavior systems for 3D action games. The project focuses on creating believable enemy encounters with patrol routes, detection systems, and combat behaviors using state machines and behavior trees.

Key Features

Implemented a multi-layered AI system featuring patrol behavior, player detection via sight and sound, pursuit logic, and combat engagement with varied attack patterns. The system uses a behavior tree architecture for extensible and debuggable AI states.
